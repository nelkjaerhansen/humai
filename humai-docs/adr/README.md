# Architecture Decision Records

Create an ADR only when all are true:

1. Meaningfully expensive to reverse
2. A future developer would reasonably wonder why it was chosen
3. Real alternatives and trade-offs were considered

Normal implementation choices stay in the refined plan, work notes, or code.
Planner considers architecture fit for every full refined plan, but that does not make every architectural choice ADR-worthy.

Prefer the format from the vendored `domain-modeling` skill (`ADR-FORMAT.md`) when creating records. Number files sequentially, e.g. `0001-short-title.md`.
